# Jackie Creative Agency Website

A modern, premium, visually stunning multi-page website for Jackie Creative Agency — specializing in Branding, Graphic Design, Printing Services, Digital Marketing, Web Design, and Social Media Management.

## Pages

- **Home** — Hero section, services overview, portfolio showcase, testimonials, CTA
- **About** — Company story, mission & vision, team, timeline, core values
- **Services** — Detailed service descriptions, process steps, pricing packages
- **Portfolio** — Filterable gallery with hover effects and category navigation
- **Printing** — Product catalog, pricing tables, quote request form
- **Contact** — Contact form, Google Maps embed, WhatsApp, business hours, social links

## Features

- Vibrant gradient color palette (Purple, Electric Blue, Orange, Pink, Cyan)
- Dark/Light mode toggle with localStorage persistence
- Scroll progress indicator
- Loading animation
- Smooth scroll reveal animations
- Animated statistics counters
- Portfolio category filtering
- Responsive across desktop, tablet, and mobile
- Glassmorphism and soft shadows
- Sticky transparent navbar with blur effect
- Animated mobile hamburger menu
- WhatsApp floating chat button
- Newsletter subscription forms
- Back-to-top button
- Google Fonts: Poppins, Montserrat, Inter, Space Grotesk
- Font Awesome icons
- SEO-friendly HTML structure

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Font Awesome 6
- Google Fonts

## Getting Started

Simply open `index.html` in a web browser, or serve the files with any static file server.

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx serve .
```
